# Eventora – Event Booking System

Eventora is a web application designed to make discovering and booking events easier. Users can browse available events, search for events by category or location, view event details, and book tickets.

The application includes user authentication, event management, booking functionality, and seat availability management. It aims to simplify the event booking process by providing a convenient platform for users and event organizers.

### Key Features
- User registration and login
- OTP-based email verification
- Browse and search events by category and location
- View event details and ticket prices
- Book and cancel event bookings
- Manage event information and seat availability
- Email notifications for bookings

### Technologies Used
- Frontend:React.js
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Authentication: JSON Web Tokens (JWT)
- API Testing: Postman

### Project Goal
To build a full-stack web application that demonstrates practical skills in REST API development, authentication, database management, and event booking workflows.
